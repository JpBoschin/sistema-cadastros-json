# 📋 Gerenciador de Cadastros com Persistência em JSON (Python)

Sistema CLI em Python para gestão de utilizadores (Clientes e Restaurantes), aplicando estruturas de dados compostas (listas e dicionários) e persistência local em ficheiros JSON.

## 📌 Funcionalidades
- Cadastro interativo de utilizadores com geração automática de ID.
- Sanitização e padronização de entradas (`.strip()`, `.lower()`, `.capitalize()`).
- Listagem formatada de registos guardados.
- Persistência automática em ficheiro `usuarios.json` (os dados mantêm-se após fechar o programa).
